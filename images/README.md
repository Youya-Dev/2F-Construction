# Photos

## Gallery
Add project photos named `project-1.jpg` to `project-8.jpg`.
They appear on the Gallery page (carousel and grid) in the same order,
and the first three also appear under "Recent projects" on the Home page.
Visitors can click any photo to see it larger.
Update each caption in `gallery.html` (and `index.html` for the first
three) to match the photo.

## Before and after
Add matching pairs named `before-1.jpg` + `after-1.jpg` and
`before-2.jpg` + `after-2.jpg`. Take both photos from the same spot so
the slider lines up. Update the captions in `gallery.html`.

Landscape photos (4:3) look best everywhere.
