# 2F Construction logo

- `logo-colour` – full logo for white or light backgrounds (navy 2F, teal roof)
- `logo-white` – full logo on navy, for dark backgrounds
- `mark-colour` / `mark-white` – the 2F roofline symbol on its own (profile pictures, stickers, app icons)

Use the `.png` files for social media, documents and printing at small sizes.
Use the `.svg` files when sending to a sign-writer or printer: they scale to any size without going blurry.

Colours: navy #1c2633, teal #0f7c7a, light teal #7fd3cd. Wordmark font: Zilla Slab Bold (free from Google Fonts).
